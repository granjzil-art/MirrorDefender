## 一、版本目标与边界

### 1.1 目标

1. 用正式卡槽替换开发期建造面板，建立清晰、可扩展的左键放置流程。
2. 建立正式运行时 HUD：建筑卡槽、地块详情、全局信息、经济信息、暂停菜单、右侧波次/重启/退出按钮、倍速与战术慢放。
3. 为每关提供 6 个可编辑镜头预设，并支持数字键平滑切换。
4. 将散落的运行时调试文字和控制入口统一迁移到游戏内控制台。
5. 以持久 `AppRoot` 承载启动选关与局内 `Main`，提供 `Catalog -> Page -> Level` 的基础六槽分页选关。
6. 所有 UI 美术、图标和卡面预留资源接口；无正式资产时使用统一的镜框/镜面/玻璃灰盒。
7. 保持 AppFlow、运行时 HUD、交互控制、时间控制、数据模型相互解耦，避免继续扩张 `Main.gd` 和开发期 `M3DebugPanel`。

### 1.2 不改变的内容

- 不改变现有塔、屏障、边障、镜子、虚像、地块元素、敌人和路径玩法；波次操作以 2026-07-27 的“逐波手动释放、可重叠、波内归一延迟”为唯一例外。
- 不调整建筑/敌人/资源等既有数值；时间行为包括战术慢放、暂停、2 倍速，以及逐波释放时建立各波调度原点。
- 不替换现有 3D 关卡画面和世界内悬浮操作，只为其接入正式交互状态并统一视觉风格。
- 边障不进入默认携带卡组，但其既有玩法保留，并可通过调试控制台继续测试。
- 本阶段不实现正式美术资产；接口、占位视觉和替换路径必须完整。

## 二、整体 UI 布局（长期结构约束）

### 2.1 运行时画面锚点

```text
程序启动：AppRoot -> LevelSelectView（每页 2×3、固定 6 槽、左右翻页）
								│ 选择合法 LevelResource
								▼
┌──────────────────────────────────────────────────────────────────────────────┐
│                                                       ┌───────────────────┐ │
│                        3D 关卡                       │ 关卡名 / 据点 HP │ │
│                                                       │ 敌人 / 建筑 / 镜子│ │
│                                                       └───────────────────┘ │
│                                             ┌──────┐  ┌───────────────────┐ │
│                                             │下一波│  │ 地块详情（按需）  │ │
│                                             │重启  │  │ 多条目滚动展示    │ │
│                                             │退出关│  └───────────────────┘ │
│                                             └──────┘                         │
│                    ┌镜子┐┌卡1┐┌卡2┐┌卡3┐┌空┐┌空┐┌空┐  金币 慢放 2x 暂停 │
└──────────────────────────────────────────────────────────────────────────────┘
							  ┌──────────────────────────┐
							  │ 暂停菜单 / 调试控制台层  │
							  └──────────────────────────┘
```

### 2.2 固定区域

| 区域 | 锚点 | 内容 | 展开规则 |
|---|---|---|---|
| 选关页 | 程序内容根，全屏 | 每页 2×3 固定六槽、页面名/页码、左右翻页 | 程序启动及退出当前关卡后显示 |
| 波次控制 | 右侧，全局信息下方 | 释放下一波、快速重启、退出当前关卡三个圆形按钮 | 局内常驻；无下一波时仅释放按钮禁用 |
| 卡槽 | 正下方居中，单行 | 独立镜子槽 + 可调数量的建筑槽 | 局内常驻；空位显示空镜面 |
| 全局信息 | 右上角 | 关卡名、据点生命、场上敌人、建筑/镜子上限 | 局内常驻 |
| 地块详情 | 右侧中部 | 地块示意与全部内容条目 | 未选中或空地块时收起 |
| 经济与时间 | 右下角 | 资源、自动慢放、1x/2x、暂停 | 局内常驻 |
| 暂停菜单 | 屏幕中央模态层 | 设置、重启、退出当前关卡 | 暂停后出现并拦截世界输入 |
| 调试控制台 | 覆盖层 | 分类开关、日志、命令输入 | F1 开关并拦截世界输入 |
| 世界悬浮操作 | 选中实体附近 | 删除、升级、旋转；镜子删除、翻面 | 仅选中对应实体时出现 |

### 2.3 响应式与层级

- 基准布局为 1600×900，同时验收 1280×720、1920×1080。
- 卡槽必须始终保持单行；空间不足时等比缩小至最小卡宽，不换行。
- 地块详情使用滚动容器管理任意数量条目，不能撑出视口。
- UI 点击必须被 UI 消费，不得穿透到世界地块/边选择。
- 推荐 CanvasLayer 层级：世界 HUD < 浮动提示 < 暂停模态 < 调试控制台。

## 三、输入与交互事实源

### 3.1 鼠标规则

- 左键承担所有肯定操作：选卡、选地块/边、放置、实体操作按钮、HUD 按钮。
- 右键只承担取消：清除卡片选择、放置预览、世界选择和地块详情，回到选择模式。
- UI 控件获取鼠标事件后必须阻止世界选择与放置。
- F1 控制台输入期间，屏蔽世界输入、镜头预设和卡槽快捷键。

### 3.2 交互状态

正式状态由 `RuntimeInteractionController` 管理；`M3DebugPanel` 不再是运行时交互事实源。

| 状态 | 进入方式 | 左键世界行为 | 退出方式 |
|---|---|---|---|
| `SELECT` | 默认/取消/任一放置尝试完成 | 选择非空地块并展开详情；选中实体时显示悬浮操作 | 选择卡片进入对应放置状态 |
| `PLACE_BLOCK` | 选择块建筑卡 | 尝试在格上放置一次 | 无论成功或失败，立即回 `SELECT` |
| `PLACE_EDGE` | 选择边建筑卡 | 尝试在边上放置一次 | 无论成功或失败，立即回 `SELECT` |
| `PLACE_MIRROR` | 选择独立镜子卡 | 预览并尝试在边上放置一次 | 无论成功或失败，立即回 `SELECT` |

### 3.3 单次放置契约

一次卡片选择只允许一次世界放置尝试：

1. 成功：完成扣费和放置，取消卡片选择、预览与建造状态，恢复选择模式和正常时间；不自动选中新建筑。
2. 资源不足：卡片通常已置灰不可选；若选中后资源变化导致不足，点击仍视为一次失败尝试并退出。
3. 达到上限：同上，失败后退出。
4. 地块/边不可放置、被占用、未命中合法格/边：显示失败原因并退出。
5. 右键取消不计为放置尝试，不产生资源变化。

### 3.4 选择模式

- 点击空地块：清除实体选择并收起地块详情。
- 点击非空地块：打开右侧详情；若含可操作实体建筑，同时保留现有世界悬浮操作。
- 选中实体建筑、实体边建筑或实体镜子时进入战术慢放；选中虚像和单纯查看地块不进入慢放。
- 右键取消当前选择并恢复正常时间。

## 四、卡槽与携带配置

### 4.1 默认结构

```text
复制镜（独立，不计建筑卡槽数） | 箭塔 | 激光塔 | 屏障 | 空槽 | 空槽 | 空槽
```

- 建筑卡槽数量是关卡/运行时可调参数，默认 `6`。
- 默认仅携带箭塔、激光塔、屏障三种块建筑。
- 复制镜固定在最左侧独立槽；它计镜子上限，不计建筑携带槽数。
- 空位显示为空镜面，不能选择。
- 数字快捷键保留给镜头预设，不用于卡槽。

### 4.2 卡片表现与可用性

- 纵向长方形；外框模拟镜框，卡面模拟镜面/玻璃。
- 主体显示建筑图像，底部显示当前等级建造费用。
- 资源不足或对应建筑/镜子达到上限时全卡置灰且不可选择。
- 已选卡增加一圈清晰金色外框。
- 资源、数量或上限改变时即时刷新可用性；如果已选卡变得不可用，保留到下一次点击并按失败尝试退出，或由控制器主动取消并明确提示，两种实现只能选一种并写测试。M6 默认采用前者以保持“点击一次即结束”的可预期性。

## 五、地块详细信息

### 5.1 展开条件

“非空地块”包含以下任一内容：

- 实体块建筑；
- 与该地块相邻边上的实体边建筑或镜子；
- 同格重叠的全部虚像；
- 大石头、尖刺、黑洞等关卡元素；
- 关卡元素的运行时状态，例如石头耐久、黑洞装填量。

### 5.2 信息模型

面板按条目动态生成并滚动。每条至少预留：

- 名称、类型、图标/预览资产；
- 实体/虚像；
- 虚像根源地块与产生镜子；
- 建筑等级、当前/最大耐久；
- 建造朝向或边方向；
- 关卡元素的核心运行时数据；
- 后续扩展字段列表。

面板只读；删除、升级、旋转、镜子翻面继续使用世界悬浮按钮。

### 5.3 对象显示配置（已实现）

- 每种建筑、复制镜和地块定义持有独立 `InspectionDisplayConfig`，不改变玩法数据。第一层 `visible` 决定该对象是否进入详情列表；例如关闭尖刺配置后，尖刺实体及其虚像均不生成条目。
- 第二层按条目字段控制图标、类型、实体/虚像、功能说明、位置、高度、建筑权限、等级、耐久、朝向、战斗、经济、容量、时序、对空、虚像来源、产生镜子和复制链深度。所有字段默认开启，以保留批次 2 已有信息。
- 隐藏字段时对应控件和占用空间一并移除；隐藏图标后条目切换为紧凑高度，剩余文字自动占满宽度。任意数量的可见条目仍由滚动容器管理。
- `display_name` 与 `function_description` 均可逐对象编辑；空文本分别回退到原有对象名称和内置功能说明。面板统一用 `功能：...` 展示说明。
- 虚像沿用其根源对象的同一份配置：根源名称、功能说明和字段开关同步生效；镜子本身使用复制镜配置，不被来源配置替代。

## 六、时间、经济与暂停

### 6.1 时间倍率优先级

```text
暂停 0x  >  自动战术慢放 0.1x  >  用户快速 2x  >  正常 1x
```

- 自动战术慢放倍率可调，默认 `0.1`；右下按钮仅控制“自动慢放是否启用”。
- 选择建筑/镜子卡或实体建筑/实体边建筑/实体镜子时触发；取消、完成放置或清除实体选择后恢复下一级倍率。
- 2x 按钮在 1x/2x 间切换；慢放期间仍记住用户选择的 2x，退出慢放后回到 2x。
- 暂停期间记住暂停前状态，关闭暂停后按当前选择和快速状态重新求值。
- 战斗、波次、经济和敌人移动使用统一缩放后的模拟时间；HUD 数字动画、弹字、控制台、暂停菜单使用不受缩放的 UI 时间。
- 战术慢放期间镜头操控保持正常手感，不随 0.1x 变慢。

### 6.2 经济显示

- 右下显示当前资源。
- 资源变化时，显示金黄色 `+x` / `-x`，从资源栏向上移动并淡出。
- 主数字在短时间内滚动/插值到新值，不能瞬间跳变。
- 连续变化事件分别产生弹字；主数字动画从当前显示值平滑追赶最新真实值。

### 6.3 暂停菜单

- 暂停按钮打开居中模态菜单，游戏模拟为 0x。
- 从左到右：设置、重启关卡、退出当前关卡。
- 首批设置项：主音量、全屏/窗口、UI 缩放；保存到 `user://settings.cfg`。
- 重启关卡必须经 `LevelLoader.reload_current_level()` 深度重载当前 LevelResource 的全套运行时状态。
- 退出当前关卡发送高层请求，经 `Main.prepare_for_level_transition()` 与持久 `AppFlowController` 返回选关页；不退出 `SceneTree`/程序。暂停菜单和确认交互不向世界穿透。

## 八、逐波手动释放与右侧波次控制

### 8.1 释放与时间语义

- `LevelResource.waves` 数组顺序是唯一可释放顺序；`WaveManager._released_wave_count` 是运行时释放游标。每次 `start_next_wave()` 只释放游标指向的一波，然后游标前进一位。
- 第一波可由兼容入口 `start_battle()` 释放；后续每波仍须再次点击右侧“释放下一波”或执行一次 `wave start`。系统不会根据前一波完成、全局秒数或 `start_delay` 自动释放未提交波次。
- 已释放波不要求先完成；玩家可在旧波仍生成或仍有存活敌人时释放下一波，因此波次允许重叠。
- `_battle_elapsed` 在第一波释放时归零，此后作为当前局的连续模拟时间。每波自己的释放时刻 `release_time = _battle_elapsed` 是该波组调度原点。
- 对一波中的每个组：`relative_delay = max(0, group.start_delay - min(group.start_delay in wave))`，实际首只生成时刻为 `release_time + relative_delay`。所以本波最早组在点击后立即尝试生成，其余组只保留作者配置的波内相对间隔。
- `wave_released(wave_number, wave)` 表示玩家释放事务成功；`wave_started(wave_number, wave)` 只在本波第一只敌人成功注册到 `CombatManager` 后发送，两者不能混用。

### 8.2 右侧按钮、悬停与路径预览

- `WaveControlPanel` 在右侧纵向固定三个圆形按钮：释放下一波、快速重启当前关卡、退出当前关卡。最后一波释放后仅释放按钮禁用，重启和退出保持可用。
- 悬停释放按钮只预览**释放游标指向的下一波**：详情聚合敌人总构成，每组显示“组N：敌人 ×数量 | 出生点N → 据点N”；不显示路径名、组延迟或出怪间隔。
- 收集下一波涉及的全部唯一 Path，经 `WaveControlPanel.paths_preview_requested -> RuntimeHud.wave_paths_preview_requested -> Main -> PathHoverPreview` 同时显示发光方向流线。
- 离开按钮、点击任一三按钮、关卡切换、暂停菜单或控制台模态打开时清理详情与路径预览。
- 预览通过 `WaveTimelineModel` 复用只读聚合，不代表旧纵向时间轴仍在正式 HUD 实例化；模型不修改 PathManager、敌人寻路或波次状态。

### 8.3 出生点、据点与目标锁定

- 出生点是独立关卡数据，不再每条路径自动创建一个；多条路径可共用出生点。出生点拥有独立 ID、名称、数字标记和格坐标。
- 据点可配置多个位置，各自拥有 ID、名称、数字标记和格坐标，但全部共享同一据点生命。运行时出生点和据点都在世界中显示数字。
- 每条 PathDefinition 必须选择一个出生点和一个目标据点；首格/末格必须分别等于两个端点，且不得在终点前经过其他据点。
- 敌人出生时锁定初始路径的目标据点。大石头阻路时，先选同目标据点的可用手工路径；无完整手工后缀时，只在“同目标手工路径格并集”上做 A*。不会游走到非路径地形，也不会转去其他据点；仍无路时攻击当前石头。
- 普通屏障/边障仍保持直接攻击，不进入大石头换路分支。
- 旧关卡保持可加载：`base_cell` 只读兼容为据点 1，旧出生点通过路径首格/波次引用唯一解析；编辑器只在用户真正修改据点时物化新数据，加载本身不改写资源。

## 九、六个关卡镜头预设

### 9.1 运行时

- 数字键 `1`～`6` 对应 6 个关卡独立机位。
- 每个机位保存：焦点世界坐标、yaw、pitch、缩放距离。
- 切换使用可调平滑时间，默认 `0.35s`；未配置的槽位无动作。
- 手动 WASD/QE/XC/滚轮输入可在过渡后继续调整；控制台输入期间不响应数字键。

### 9.2 关卡编辑器

- `LevelResource` 持有 6 个可选镜头预设资源。
- 关卡编辑器新增独立“镜头”页/组件，不继续堆积到已有 1300 行级面板脚本。
- 支持从当前编辑视角写入槽位、跳转预览、清空槽位，并显示是否已配置。

## 十、游戏内调试控制台

### 10.1 打开与分类

- `F1` 打开/关闭；打开时捕获键盘与鼠标。

## 十一、模块化架构

### 11.1 推荐模块

| 模块 | 职责 | 禁止承担 |
|---|---|---|
| `RuntimeInteractionController` | 模式、卡片选择、单次放置、取消、世界选择协调 | 绘制卡片、保存资源数值 |
| `GameTimeController` | 正常/快速/慢放/暂停的优先级与 `Engine.time_scale` | UI 具体按钮样式 |
| `RuntimeHud` | 组合各 HUD 子场景并连接公共信号 | 复制玩法 Manager 状态 |
| `BuildCardBar` | 卡槽视图、可用性表现、选卡信号 | 直接放置建筑 |
| `TileInspectionService` | 将格上实体、边实体、虚像、元素转换为只读模型 | 修改建筑/地块 |
| `TileInspectorPanel` | 展示检视模型 | 查询世界树实现玩法判断 |
| `GlobalInfoPanel` | 展示全局只读数据 | 自维护敌人/建筑计数 |
| `EconomyPanel` | 资源滚动数字和增减弹字 | 改资源 |
| `PauseMenu` | 模态 UI、设置、重启与退出当前关卡请求 | 实现关卡装配或退出程序 |
| `WaveControlPanel` | 下一波/重启/退出三按钮、下一波详情与路径预览请求 | 维护释放游标或直接装配关卡 |
| `WaveTimelineModel` | 波次资源到敌人/路径摘要的只读投影；仅供下一波详情复用 | 改写波次调度或绘制现役纵向时间轴 |
| `AppFlowController` | 持久拥有选关页或一个 Main，提交/回滚局外到局内切换 | 直接配置 Grid/Tile 或保存进度 |
| `LevelSelectCatalog/Page/View/Slot/Thumbnail` | 作者顺序分页、固定六槽、只读缩略图与关卡选择信号 | 解锁、星级、进度存档或玩法节点实例化 |
| `PathHoverPreview` | 下一波悬停路径流线 | 修改手工路径 |
| `CameraPresetDefinition/Controller` | 关卡数据、平滑切换 | 拦截普通相机输入 |
| `DebugCommandRegistry/Console` | 分类、命令注册与执行 | 把业务命令硬编码在 UI |

### 11.2 数据与依赖边界

- `AppFlowController` 是程序级生命周期根；任一时刻只提交一个 `LevelSelectView` 或一个已成功首载的 `Main`。
- `Main.gd` 只负责局内装配和高层生命周期，不继续承接具体 HUD 交互；实际资源装配仍只经 `LevelLoader`。
- UI 通过信号、Callable 和只读 ViewModel 连接 Manager；Manager 不依赖具体 Panel 类。
- 开发期面板可作为兼容适配层，但正式状态和数据只能有一个事实源。
- 每个 UI 子系统使用独立 `.tscn + .gd`，公共镜面风格进入 Theme/StyleBox/Shader 资源。
- 所有动态连接必须在释放/切关时断开，重复装配不得叠加信号。

## 十六、2026-08-06 运行时关卡作者工具扩展

左侧开发者入口“运行时关卡编辑”在现役 M6 HUD 内保持单一工作区，不新增第二套浮动编辑器。工作区标题固定；标题下方使用单一纵向滚动区，从上到下为：选择工具、地块类型调色板、高度刷、斜坡参数、Stuff 调色板、作者断路覆盖、当前选择、撤销/重做/保存、状态信息。窗口高度不足时滚动查看全部工具，不允许内容越过面板边界。

- 地块类型：从 `res://resources/terrains/*.tres` 读取 `TerrainDefinition`；悬停格显示真实模型/材质候选，点击写入该格。命中坡体时整段坡体基底原子修改，禁止一条坡逐格混用地形。
- 高度：固定1～4层。悬停显示完整体素堆叠结果；命中坡体或会破坏斜坡高低连接约束时红色拒绝，不生成非法数据。
- 斜坡：坡长1:1～1:4，基础层1～3，覆盖地形可选“跟随基底”或指定 Terrain。点击格代表最低坡格，方向指向高端；悬停直接实例化真实候选，`R`/面板旋转立即更新方向。选择已有坡后可旋转、修改覆盖地形或整段删除。
- Stuff：继续使用显式 `StuffCatalog`、真实模型绿/红预览、断路作者警告和同格循环选择。
- 所有 Terrain/Ramp/Stuff 操作共享一条撤销/重做历史。预览不进入历史；点击提交才形成一个原子操作。放弃退出恢复开启工作区时的完整快照。
- “保存元素”保持 Stuff-only 兼容语义；有 Terrain/Ramp 修改时显式提示使用“全量保存”。全量保存写入 Grid、Ramp、Stuff 与当前实体建筑/复制镜初始陈列；不保存路径、波次、镜头、经济和战斗临时状态。

地形候选通过 `LevelResource.validate_runtime()` 后才临时装配。预览期间只重新采样建筑、复制镜、Stuff、路径、出生点与据点的表面位置，不重置生命、耐久、攻击冷却或效果容量。
